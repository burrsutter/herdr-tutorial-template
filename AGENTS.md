# Practice scaffold

- This checkout is one exercise repository. Its role is the local directory name: hello, api, web, or batch.
- Wait for the human's task before implementing code. Stay inside this checkout; sibling repositories are read-only unless the task explicitly says otherwise.
- hello and api use TypeScript on Node.js. Backend APIs use TypeScript; use node:http unless the task names another framework.
- web and batch use Python's standard library. Add tests/__init__.py when creating Python tests so root-level unittest discovery finds them.
- Source and tests are intentionally empty at the start. Never count an empty test run as success.
- The reviewer is read-only. The human decides when to accept and commit.
- Do not install packages, launch another agent, publish, push, or delete files/repositories without the human's explicit task instruction.
- The template remote is public starter material. Never push an exercise result to it.
